# Jupiter · Réplica de diseño web (PHP MVC + MySQL + Bootstrap)

## Ejecutar en local (XAMPP)
1. Copia la carpeta en `C:\xampp\htdocs\jupiter`.
2. Inicia **Apache** y **MySQL** en XAMPP.
3. En http://localhost/phpmyadmin → *Importar* → `database/jupiter_db.sql`.
4. Abre http://localhost/jupiter/

## Estructura MVC
`index.php` (router) · `controllers/` · `models/` · `views/` · `config/` · `assets/` · `database/`

## Tecnologías
PHP 8, MySQL, Bootstrap 5, Swiper (carrusel), AOS, Bootstrap Icons, Google Fonts.
